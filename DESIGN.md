# DESIGN.md — вариант «Light» (по промту 1, Axion Studio)

Источник направления: `дизайн/дизайн промт1` в папке проекта. Перенесено на многостраничный сайт агентства «Биба и Боба».

## Токены
| Роль | Значение |
|---|---|
| Фон первого экрана | `#EFEFEF` + шейдер (Swirl → ChromaFlow `#ff5f03` → FlutedGlass → FilmGrain) |
| Фон разделов | `#FFFFFF` и `#F5F5F5` поочерёдно |
| Текст | `gray-900 #111827`, вторичный `gray-600 #4b5563` |

## Компоненты
- Навигация-пилюля (белая, 5px padding), логотип-круг «ББ», часы «по Москве», CTA «Обсудить проект»; мобильная нижняя шторка.
- Первый экран: на главной во всю высоту, на внутренних по высоте контента; метка раздела, H1, lede, две кнопки, карточки фактов.
- Бейдж раздела: номер в круге + пилюля с подписью (нумерация = порядок разделов главной).
- Инфографики: «этапы» (нумерованные карточки), «цифры» (крупные значения), «сравнение» (таблица в рамке).
- «Из практики» тёмная карточка, перебивка CTA оранжевая, FAQ на `<details>`, карточки «Смотрите также», карточки кейсов с расширяющейся кнопкой (из секции 3 промта).

## Отступления от промта (осознанные)
- React SPA заменён на Astro: каждая страница отдаётся готовым HTML (нужно для SEO), React только островком для шейдера.
- Видео из карточек кейсов промта не используются: это работы другой студии. Карточки показывают цифры наших кейсов.
- Тексты «Certified Partner / Featured», «Q1 2026», «London» заменены на правдивые: «Работаем с 2018 года · SEO · Авито», «Работаем удалённо по всей России», время по Москве.
- Изображения секции «О нас» из промта сохранены как нейтральные иллюстрации; внутренние страницы берут фото с Pexels.

## Блочная раскладка контента (обновление 03.10.2026)
- Плагин `src/lib/rehype-layout.mjs` раскладывает markdown по блокам: каждый H2 становится карточкой с номером, подразделы H3 собираются в сетку карточек, списки вида «**заголовок** текст» превращаются в карточки.
- Инфографика: этапы показаны нумерованными карточками, цифры крупными плитками, таблицы сравнения на узком экране превращаются в карточки с подписями колонок.
- Фото из `images.json` (inline-1…3) расставляются по разделам: рядом с текстом или широким кадром.
- Колонки всех сеток считаются по ширине блока (container queries), поэтому ряды всегда заполнены и текст не сжимается.
- Шапка: выпадающие списки подразделов по каждому разделу (структура в `NAV` из `src/lib/site.mjs`), на телефоне меню с раскрывающимися группами.
- Боковое оглавление показывается с ширины 1280 пикселей.

## Логотип и превью (обновление 03.10.2026)
- Знак без названия: облачко сообщения (заявка) с меткой-спутником в вырезе; большой и малый круг означают двух партнёров. Компонент `src/components/Logo.astro`, иконка вкладки `public/favicon.svg`. Название агентства в шапке и подвале не выводится.
- Подпись над H1 (eyebrow) на первом экране убрана.
- Карточки «Смотрите также», кейсов и каналов показывают превью. Источник выбирает `src/lib/previews.mjs`: своя картинка из `src/data/previews.json`, иначе фото первого экрана страницы. Свои картинки кладутся в `sites/previews/light|space/{slug}.png` и загружаются скриптом `sites/previews/import_previews.py`; промты для ChatGPT в `дизайн/промты-превью-chatgpt.md`.
- Тексты сокращены примерно вдвое (полные версии в `drafts/content-full-2026-10-03/`).
- Кейсы на странице «Кейсы» и на главной выводятся мозаикой (компонент `CaseMosaic.astro`, по образцу портфолио addu.ru): вкладки разделов (поле `case.category`), ряды 8+4, 12, 6+6, 4+8 колонок, пересчёт при фильтре. В плитке предмет на прозрачном фоне из `src/data/case-art.json` (загружается из `sites/previews/cases/`), пока его нет, стоит фото с переходом в цвет плитки.
- Квиз-калькулятор «С чего начать» на главной (`src/components/QuizCalc.astro`): 4 вопроса, рекомендация канала и услуг, ориентир обращений по Авито по средней цене обращения из кейсов раздела, форма с ответами квиза.
